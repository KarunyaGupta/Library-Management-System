## 1. Introduction
### 1.1 Purpose
This document outlines the complete Software Development Life Cycle (SDLC) for the Library Management System. It provides a comprehensive overview of each phase, deliverables, and methodologies used throughout the development process.

### 1.2 Scope
The SDLC covers all aspects of development from initial planning to maintenance, ensuring a systematic approach to creating a robust library management solution.

- Each section contains specific deliverables
